راهنمای نصب MAHO روی Chromebook

مهم: برنامه PWA از داخل فایل ZIP یا با آدرس file:// نصب نمی‌شود. باید پوشه روی HTTPS یا localhost باز شود.

روش ساده برای آزمایش:
1) فایل ZIP را Extract کنید.
2) پوشه را روی یک هاست HTTPS قرار دهید (مثلاً GitHub Pages یا Netlify).
3) آدرس index.html را در Chrome باز کنید.
4) از نوار آدرس روی آیکون Install بزنید، یا از منوی سه‌نقطه Chrome گزینه Install MAHO را انتخاب کنید.

اطلاعات برنامه در localStorage همان آدرس ذخیره می‌شود. قبل از تغییر آدرس یا حذف برنامه، از داخل MAHO نسخه پشتیبان بگیرید.
